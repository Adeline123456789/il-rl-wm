# U1 seed0：完整训练后的初步稳定性证据

2026-10-16。仅开发seed0，最终测试seed20000尚未访问。U1仅增加SAC双critic隐藏层LayerNorm，预登记见[U1_CHANGE](../U1_CHANGE.md)。与U0共享BC与初始Linear参数/训练seed，但分别重训C阶段，后续实际轨迹不同；不是同一个已学习C checkpoint的分叉。

两个方法均为262144 C预热＋262144规划训练交互。固定最终模型的16个完整验证回合如下；不挑中间峰值。

| 推理方法 | U0成功数/16 | U1成功数/16 | U1平均回报 |
|---|---:|---:|---:|
| 冻结IL | 0 | 0 | 0 |
| 裸SAC | 0 | 16 | 187.00 |
| IL＋SAC＋WM | 0 | 13 | 121.25 |
| 无IL的SAC＋WM | 0 | 15 | 172.69 |

U1没有复现这条U0开发运行的末期崩溃，但规划器在这些回合仍未优于裸SAC。原C续训已为16/16，C-LN续训也已完成16/16、平均回报187.38（U1裸SAC187.00）；不能把“比崩溃U0好”写成优于稳定SAC对照或证明WM带来收益。独立训练seed1–4、额外任务以及正式100回合评测仍未完成。

同一组已发布真实输入（2048 expert＋2048 U0第196608步快照回放样本）给出以下在线样本统计。箭头为第196608步→固定最终步；只是模型数值与Bellman一致性诊断，不是MC校准。

U1自身快照回放输入的最终soft Q均值42.21，纯任务价值均值62.22、负值7.37%；这些样本与U0公共输入分开保存，不能混合当相同分布。U1仍有不合理负任务价值，不宣称归一化解决校准。它的最终训练批Q1约40.78、双Q TD loss .2335、alpha .05761；U0对应约312.89/280.61/.32556。训练批数据不同，固定输入结果才用于直接数值比较。

全部真实回放的末8192步，U0正奖励0%、抓取1.70%、平均目标距离.617m；U1分别72.02%、81.05%、.172m。全部32区间均保留，未只截取有利片段。U1全段IL执行97037（37.02%）、规划SAC112436（42.89%）、随机SAC52671（20.09%）；U0的IL为30.06%，随机SAC同为20.09%。IL介入反而增加，因此该结果不支持“改善来自减少IL执行”的解释。首次成功所在动作来源仅是时序标签，不能据此分配因果信用。

执行审计验证256个采样动作批次与回放逐位一致、IL权重不变、WM/纯任务价值实际更新及优化器步数。U1可训练参数602423，比U0多3072；规划段整作业1204.58秒，U0为1093.20秒，均包含初始化/验证，不能当作独立吞吐基准。两者整卡采样峰值均4703MiB，2秒采样可能遗漏瞬时峰值。新C-LN续训启动源码压缩包122617字节、96文件，全部与启动哈希清单匹配；旧U1作业不倒填该快照。
