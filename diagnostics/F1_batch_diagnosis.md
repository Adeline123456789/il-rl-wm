# F1：本批候选排序仍不可辨识

四次已完成的真实分支探测均未观察到超过预登记容限的候选回报差异。因此不能由这些结果判断评分排序好坏，也没有直接证据把排序错误确定为 U0 崩溃的瓶颈。零 regret、没有错误接管/拒绝记录不能当作可靠性证明。

每次冻结 9 个候选、8 个状态、2 次重复；首动作后学生续接与完整 H2 后学生续接分开统计，续接 400 步。全部状态在同一快照内重复 reset 和固定前缀重放的观测误差均为 0，重复回报差也为 0。这不是任意中途状态恢复，也不意味着跨模型状态配对。

| 模型快照 | 学生前缀 | 每目标可排序对 / 近似平局 | 同状态最大候选回报差 | GPU作业秒 | 诊断交互 |
|---|---:|---:|---:|---:|---:|
| U0 final | 40 | 0 / 288 | 0 | 434.37 | 127040 |
| U0 step196608 | 40 | 0 / 288 | 1.0 | 456.24 | 127040 |
| U0 step196608 | 20 | 0 / 288 | 1.0 | 482.91 | 121120 |
| U1 step196608 | 20 | 0 / 288 | 1.0 | 470.83 | 121120 |

两个续接目标分别得到表中相同的可排序计数；没有合并为更多独立训练重复。gamma=.99 下未观察的非负 continuing 回报尾段上界为 1.7950553，排名容限保持 max(1.0, 尾段上界)。全部 496320 诊断交互均未用于学习。

U0 final 所有候选都失败。U0 step196608 在 prefix20 时 8 个状态均已抓取，目标距离 0.0055–0.0166m；prefix40 时也位于成功保持区。两次 U0 探测保存的前 20 步观测逐位一致，短前缀没有产生期望中的决策分歧。U1 prefix20 时也全部抓取，目标距离 0.0050–0.0419m，但其中一个状态的全部候选续接回报为 0；其余状态接近成功保持区。不同状态之间的成功/失败差异不能作为同一状态候选排序的信息。

H2 评分的误差分解中，SAC 候选短期奖励 / 动力学终端项 / 真实末状态价值残差 MAE 分别为：U0 final 约 0 / 1.543 / 28.863，U0 prefix40 约 .100 / 2.251 / 19.736，U0 prefix20 约 .135 / 1.969 / 20.102，U1 prefix20 约 .087 / 1.779 / 22.212。价值残差数值较大，但绝对误差不等于相对排序误差；各探测状态和候选不同，不把数值变化解释为 LayerNorm 的配对因果效果。误差可相互抵消，MAE 不直接相加。

按[补充诊断登记](../configs/f1_prefix20_followup.json)停止本批前缀搜索，不降低容限，不为制造可排序样本继续消耗仿真。分类为“诊断状态/候选缺乏可辨识差异，排序假设证据不足”。后续批次如专门研究排序，应先独立登记覆盖接近、抓取转换和扰动状态的采样方案及预算；本批优先完成已登记的独立训练种子与额外任务。
