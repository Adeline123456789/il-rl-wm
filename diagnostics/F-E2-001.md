# F-E2-001: weak sparse-reward exploration in the first SAC development run

Evidence: e2-sac-a-full-001 completed 262144 interactions and 64528 gradient updates. Among 1296 completed training episodes, one achieved success and the reward sum was six. All 80 validation episodes across five fixed snapshots had zero success, including the final 16. This is a finite development run, not a convergence result.

The final logged SAC Q values were approximately 31 while task rewards were rare. This is not, by itself, evidence of task-value overestimation: these Q functions include entropy. It is a concrete reason not to use them as if they estimated pure task return in a reward-only planner score. A separate pure-task evaluator is defined in configs/wm_u0_design.md; it is not yet implemented.

Competing explanations include sparse exploration support, insufficient training, and implementation/reset effects. The final replay contained one stale initial contact observation, so this run remains protocol v1. Repeat A with corrected v2 resets and compare B/C under the same budget before attributing an effect to initialization or expert replay. Preserve the original run and its raw observations.

No research modification is claimed here. The C baseline and the reset repair were already required by the initial protocol. Failure-focused literature is being verified; no dense or stage reward will be introduced into the main experiment.
