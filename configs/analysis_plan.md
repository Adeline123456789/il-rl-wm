# 首批结果归并规则（最终测试前登记）

依据`final_evaluation_plan.json`的task、training_seed、variant和training_interactions归并，再区分评测method。不能把多个训练变体都因推理方法名为`sac`而混在一起。导出权重和评测入口核对任务、训练seed、总真实训练交互及原始checkpoint哈希。

主关注指标是完整轨迹的无IL `sac_wm`成功率及回报，同时展示裸SAC和含IL规划、固定IL。必须列出全部训练seed和失败；只报告固定最终模型，不选中间峰值。相同seed下的U0/U1从相同BC与匹配初始Linear权重开始，但实际轨迹会分叉，不称为同状态反事实。

100评测回合只评估一个固定训练模型。先列每个训练seed的原始成功数/100，再给跨训练seed均值、样本标准差和逐seed差值；不把环境步、100回合或多个checkpoint作为独立训练重复。开发seed0单独标记，独立重复seed1/2另列；如扩展seed3/4须保留预登记顺序。少量seed不宣称统计充分，不用显著性星号代替个体结果。本文档尚未计算最终测试统计。

A/B/C阶段为262144在线交互；U0/U1及C续训为包括预热的524288。RLPD的262144和524288阶段分别与相应预算比较，不能把较短A/B的分数当作等交互的最终对手。所有预热、验证、诊断、失败与最终测试另计资源；BC/WM离线更新也报告。不同任务不同horizon，逐任务展示成功率/回报，不让跨任务平均掩盖失败。

RLPD是等真实在线交互而非等计算比较：十critic、UTD20、更多同一expert数据重采样都明确报告。U1只多3072个可训练critic参数；不能把其成本当零，也不称完整RLPD/DroQ。模型/候选生成不计真实探索，实际执行来源和新增成功仅按真实replay复算。来源与成功的关联不能当因果信用分配。

回放原始记录的时间上限为Pick/Stack50、Peg100，原始动作重放在这些truncation标记后仍继续且不自动reset；物理转移和原始标签都保留。主训练/评测上限固定200/300/400。统一continuing任务在时间截断处从物理末状态bootstrap；expert WM窗口只在真实同一记录内取连续转移，online窗口不跨自动reset。不能把原回放的truncated标记误写为任务失败或隐去两种时限。

F1只在匹配检查通过、回报差超过尾段误差容限时给排名指标。无可分对时报告不可辨识；不以低WM loss、模型分歧或SAC soft Q的数值范围替代真实候选比较。行为时间线与损失的先后只能约束竞争解释，不能证明因果链。

可复算入口为`scripts/summarize_final_results.py --output artifacts/final-results-001`，只读JSON/逐回合日志，不加载模型或运行仿真。它输出完整登记条件CSV、逐训练seed结果、按开发/独立重复分开的均值与样本标准差，以及相同task/seed/预算/method下的U1−U0和C-LN−C差值；未运行/运行中/失败条件保留空成绩。完成项必须通过100完整回合、原始计数与结果一致性检查。软件测试使用明确的合成数据，不充当真实实验。首轮真实目录预检尚无最终测试，因此60条件全部pending；随后登记seed3/4后为88条件。
