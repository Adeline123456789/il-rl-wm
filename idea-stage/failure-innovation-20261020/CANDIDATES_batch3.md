# 第三批（最后一批）：后续反馈会不会抹去候选差异？

## C1 v1：区分候选坍缩与闭环结果不敏感

本批承认A2/A3/A4、B1/B2均没有通过8分门槛。DeepSeek call3提出“Actor支持坍缩+排斥正则”的新建议，但它只是审稿建议，不是事实。

**新增原始数组核验**：candidate_spread_audit.json分别计算全部9候选与索引1–8的SAC候选，排除IL候选造成的假多样性。崩溃前两U0与U1的SAC首动作最大成对RMS在各状态约0.086–0.233，中心化动作矩阵第四奇异值约0.027–0.067；这些8状态里4维动作没有数值秩坍缩。实际第一步42维观测在候选之间也有元素差异（混合单位，不当作米或动力学质量）。但保存的所有候选末端成功结果一样。崩溃后某状态可低秩，不能据局部例子解释全部快照。

**新科学假设**：候选在动作/短期状态上可区分，但固定学生续接对任务成功差异不敏感；局部动作扰动可能被反馈纠正、或都落在同一个失败/成功盆地。它与“动作候选没有多样性”不同。现有数据没有长程完整状态，因此不能声称已观察到轨迹收缩、合流或唯一物理原因。

**希望成立的精确贡献**：在相同冻结候选与同一续接下，系统性分解“proposal差异→真实短期状态差异→续接保持/抹除差异→任务结果差异”，找到一个能预告WM排序何时有价值的闭环响应时间尺度，而不是继续用动作距离或模型分歧代替。单一候选机制是按该响应指标安排有限真实探索片段长度；正常规划仍E=1，SAC仍单步闭环，WM原主干不删。该机制尚未形式化成熟，不能称新算法。

**最近邻与碰撞风险**：Beyond Visual Quality直接发现动作分散不等于结果覆盖、机会集中在少数决策；Why Does Action Chunking Improve BC? arXiv2608.02547研究非Markov表达、延迟策略、隐式集成；gSDE处理周期重采样噪声；JSRL本就提供连续学生控制。反馈稳定性/敏感性/可达盆地也是经典控制概念。若所谓“响应时间尺度”只是换名，创新应判低。不能把四段诊断图拼装当新机制。

**最便宜的可否定试验（仅提案）**：冻结已有稳定SAC与WM，从全新开发reset执行预先确定的前缀，分接触前/保持/失败恢复三层，但阶段信息仅用于离线诊断分层。选24状态，2个预先固定候选、4重复；分别执行首动作后同学生续接、连续2/4步闭环SAC片段后同学生续接。完整实际状态/控制器/随机信息恢复先验证，不支持时用原重置+固定前缀并保留限制。比较等动作功率、等真实步数的iid/gSDE与纯随机方案，不添加奖励、不用最终测试state训练。所有匹配前缀、诊断、重复都计费；24×2×4×3×200=115200分支步上界，另计前缀，不能拿400Hz纯随机吞吐推算有模型闭环GPU秒。若2个候选无差或区间过宽，则null；不能按结果搜更多状态后只报成功。

**kill**：BVQ/已有控制敏感性已经包含本主张；仅发现稳态比边界鲁棒这种常识；gSDE/固定片段长度同样有效；所谓指标只与动作幅度相关；没有独立预留分布上的regret/无IL净收益，或预测代价超过被省掉的规划代价。一个单seed探索pilot不提供可投稿证据。当前无GPU授权，不运行。

## A1 v2：对原文“DR校正能打断选择性反馈”作最后核验

原文路径可以做受控工程研究，但不能默认原创。当前系统本来就以实际执行转移更新WM/Q，Soft IBRL也通过非零执行机会纠正低估；因此“前人只有盲目评分、我首次增加真实纠错通道”表述不成立。可能的窄delta只是：在固定候选、固定续接快照、有正支持的已知选择概率下，用交叉拟合DR估计相对优势，检验是否比等数据量Soft IBRL/普通回放更快降低真实候选regret。还要有同容量Q-only、WM+无校正与均匀审计对照。DR伪标签期望正确不保证逐状态排序，也不处理跨快照漂移；增加residual头不自动优于训练原Q。

最近邻IBRL/Soft IBRL、MoDem-V2、Dudík等DR；未来先确认真实可分对，成本计入训练。kill：没有可分对、等数据随机抽查效果相同、Q-only解释全部收益，或无IL不改善。此项没有加入新的DR估计理论，若只标准DR应用应诚实给低创新分。
