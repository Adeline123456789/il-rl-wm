# 从失败中保留什么、撤回什么

证据基线：本地既有106正式条件、四次F1探测与R0/R1完整开发日志；CPU复算见existing_recomputed.json。远端锚点21935f2。没有新增训练或仿真。

1. **优化了代理指标，却未改善闭环。** D1低动作误差但均值成功1/100；C1近似复制当前首动作仅保住初始均值15/100，随机1/100；U2减小专家状态均值漂移，最终仍0/100。结论只否定这些配置下的“低MSE/复制/短期保持即可继承”充分性。方差、覆盖、Critic、饱和、历史差异都是竞争解释，不能合并为已证明的根因。
2. **强教师的定义没有和学生目标完全一致。** 集成教师73/100成功一次、末步仅8/100；当前学生目标是无历史首动作函数。73%不能作为当前蒸馏对象的教师基准（对应首动作14%）。这不是仅复制更多参数就能修好的问题；任何新增历史接口必须明确登记。
3. **初始化、数据与价值稳定性被混为贡献。** T6相对T4只多专家混合，支持整体数据干预；R0/R1/R2开发31/30/34（40回合）又说明随机起点也能学。不能据单seed断言ACT无用，但必须撤回“79%证明ACT迁移有效”。LayerNorm是已知机制；旧C-LN续训93.5%也不依赖新增WM规划。
4. **真实探索比例不能证明探索有效。** 历史约20%实际SAC执行已审计，但T5零正奖励、U2仅6条。应同时记录连续控制长度、成功支持、失败恢复和覆盖，不能拿动作熵替代。gSDE/参数噪声/JSRL已涉及相关解法，常规改动不能包装成创新。
5. **没有建立排序问题存在的前提。** 四次F1共496320额外环境交互仍0可分对，accuracy=null。崩溃后全失败，崩溃前多在成功保持区，且continuing tail界1.795大于观察差≤1。原因可能是真无机会或诊断低功效，当前不能区分。不能用regret=0证明裁判准，也不能因为WM绝对误差大就证明它选错。
6. **成功一次并不代表稳定成功或规划净收益。** 旧U1无IL WM相对同模型裸SAC成功+1.25pp，回报−3.10，且有额外计算。四个训练seed保留；不能只报正的成功率。新研究若关注持续保持/first-passage，必须用新开发与测试协议预登记，禁止改写旧正式口径。
7. **文档中的统计修补并不自动是算法创新。** DR已知随机化概率可消除部分选择偏差，但不免费产生逐状态反事实，不保证非平稳下每个候选可靠。普通RL也会用真实回放纠正价值；不能把已有系统说成完全没有纠错通道。新增校正须胜过等数据随机执行/Soft IBRL、Q-only和强Critic，所有分支成本计费。
8. **状态文件不是进程事实。** R3 manifest已signal15退出，旧队列仍training。中断原因来源未知，不能当科学失败或补造最终值。本轮只报告差异，不复活队列、不借剩余额度启动研究。

本轮研究可以失败；既有有界负结果不会因为候选得高分而改成正结果。所有未来新实验方案都是未授权提案，最终保留原SAC+WM无IL目标。
